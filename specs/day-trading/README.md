# Day Trading Spec Scaffold

This folder contains the initial operational specification scaffold for a day trading fork of the SDD template.

## Status

- Domain: Day trading
- Role model: neutral scaffold created from explicit human input
- Agent implementation: not yet started; this repo currently holds specs only
- Knowledge base: not yet available; placeholders are intentionally neutral

## Included Specs

- [strategic.md](strategic.md) — objectives, decision principles, constraints
- [execution.md](execution.md) — actions, preconditions, approvals, authorization
- [observability.md](observability.md) — data sources, metrics, alerts
- [collaboration.md](collaboration.md) — roles, visibility, communication paths
- [review.md](review.md) — review cadences, analysis, feedback loop

## Current Working Assumption

This scaffold is intentionally non-prescriptive. All domain semantics should be reviewed and replaced with explicit facts before production use.
