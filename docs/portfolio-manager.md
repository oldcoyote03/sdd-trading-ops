# Portfolio Manager Guide

Use generic placeholders unless the human has explicitly defined the domain and role semantics. The goal of this template is to create a structurally useful draft without inventing domain-specific meanings.

## What is This Role?

This role oversees the portfolio objective, prioritization, and operating constraints for the day-trading system. It coordinates priorities and ensures that decisions remain aligned to organizational or strategic intent.

## Day-to-Day Responsibilities

What does someone in this role do on a typical day?

- Review the current operating picture and priority list
- Confirm allocation or positioning priorities within approved boundaries
- Monitor exceptions and trigger escalation when thresholds are breached
- Review outcomes against planned objectives and update decision input

## What You See

What visibility does this role have in dashboards, reports, and alerts?

- Current workload and portfolio status
- Operational health indicators
- Escalation alerts requiring action
- Summary-level review of performance and exceptions

## Decision Authority

What decisions can this role make, and within what constraints?

- Set or adjust portfolio priorities: Within approved operating boundaries and documented policy
- Approve or reject non-routine action: Only when within defined authority and review scope
- Escalate a policy or threshold issue: Requires documented review and follow-up path

## When to Escalate

When should this role request help from others?

- Thresholds or limits crossed → escalate to Compliance Officer or designated reviewer
- Policy ambiguity or exception request → escalate to the relevant approver
- Operational disruption impacting portfolio objectives → escalate to the execution leadership path
