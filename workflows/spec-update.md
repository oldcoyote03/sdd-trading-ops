# Spec Update

Follows [specs/day-trading/spec-maintenance.md](../specs/day-trading/spec-maintenance.md).

## Steps

1. Choose the spec(s) to update (human names them, or all).
2. List unresolved placeholders and open gap flags for those specs.
3. Find relevant KB notes for each placeholder or gap.
4. Draft changes, citing notes or gap flags where they apply. Leave unsupported placeholders in place and add them to Open Questions.
5. Run the consistency checks across all specs.
6. **Checkpoint**: present the diff with rationale for human approval.
7. Apply and commit only the approved changes.

## Done When

- [ ] Proposal reviewed by a human
- [ ] Approved changes committed with a clear message
- [ ] Knowledge base unchanged
